I made Membrane Mania, a review game built from your two worksheets. I played through both rounds and the finale in a browser and it works without errors. It’s private to you until you share it.

  • Round 1: Label It. Students place your 15 labels on a membrane diagram I drew to match yours, including the close-up box with the vesicle and the single phospholipid. They can drag a label onto its box or tap a label and then tap a box, which works better on Chromebooks and phones.
  • Round 2: Function Match. Each of your 16 function descriptions comes up in random order, and students tap the matching structure from the word bank.
  • Full Challenge runs both rounds back to back.

Phil the Phospholipid sits beside the game (at the bottom of the screen on phones) and talks students through it:

  • Wrong answers: he gives a clue, such as “Glyco means sugar…”. If a student puts “Integral protein” on the aquaporin, glycoprotein or pump, he says that’s technically true but asks for the more specific name.
  • Hint button: the first press gives a clue. The second press makes the right box glow in Round 1, or narrows the choices to three in Round 2.

Celebrations:

  • Correct labels: each one sets off a burst of tiny phospholipids along with either a small vesicle that floats up and pops, a splash of water molecules, or a spray of sodium ions. Phil also bounces and cheers (“Selectively permeable? More like selectively AWESOME”). Streaks of 3, 5, 8 and 12 get their own cheers, and the bigger streaks get a bigger burst.
  • Finale: phospholipids fly in from every edge of the screen and form a giant vesicle around Phil. It pulses, then bursts (“Exocytosis complete!”) into a shower of phospholipids, water molecules and ions while Phil dances.

The finale screen also gives students a rank from “Budding Vesicle” up to “Membrane Master”, 1–3 stars, and their score, first-try accuracy, best streak and hints used. Below that, a “Worth another look” list shows each structure they missed with its function, which you could have students screenshot as an exit ticket.

There are short sound effects, and students can mute them with the button in the top bar.

You’ll use GitHub Pages, GitHub’s free hosting for web pages. The whole game is one file, index.html, which I’ve sent you. Download it first.

1. Create a repository

  • Sign in at github.com, click the + in the top-right corner, and choose New repository.
  • Give it a short name like membrane-mania. The name becomes part of the web address.
  • Set it to Public. Free GitHub accounts can only publish public repositories.
  • Click Create repository.

2. Upload the game

  • On the new repository’s page, click uploading an existing file. If you don’t see that link, click Add file → Upload files.
  • Drag index.html into the box. The file name must stay exactly index.html, because that’s the page GitHub shows first.
  • Scroll down and click Commit changes.

3. Turn on GitHub Pages

  • In the repository, click Settings, then Pages in the left sidebar.
  • Under Build and deployment, set Source to Deploy from a branch.
  • Under Branch, pick main, leave the folder as /(root), and click Save.

4. Get your link

  • Wait a minute or two, then refresh the Pages settings page. A box at the top will show your web address: https://YOUR-USERNAME.github.io/membrane-mania/.
  • Open it to check the game, then share that link with students or post it in your LMS.

Changing the game later: go back to the repository, click Add file → Upload files, drop in the new index.html, and commit. It replaces the old version, and the live site updates within a minute or two.

Things to know:

  • Anyone with the link can play. Because the repository is public, people can also see the file itself. That’s fine here, since it’s just a review game.
  • School filters: some school web filters block github.io sites. Open the link once on a school computer before using it in class.
  • The Claude link still works. The artifact link you already have still opens the game, but students would only see it if you shared that link with them. GitHub gives you a regular public address that doesn’t depend on Claude.
